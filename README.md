# מעקב חממות וניל

אתר דיווח לעובדים ודשבורד למנהל. הנתונים נשמרים ב-Google Sheets, והשרת הוא Google Apps Script. מזג האוויר מגיע מ-Open-Meteo (מודל ECMWF, שנמדד כמדויק ביותר לשניר).

```
docs/           האתר (GitHub Pages). קבצים סטטיים בלבד, בלי שלב בנייה
apps-script/    השרת. Code.gs ו-appsscript.json, מודבקים לעורך של Apps Script
scripts/        mock-server.js, e2e.js ו-gas-harness.js (בדיקות). build_workbook.py ו-vanilla-greenhouses.xlsx הם גיליון לדוגמה ואין בהם צורך
research/       מחקר על מערכות מעקב ואגרונומיה של וניל
```

## איפה הנתונים נשמרים

כל הנתונים נשמרים בקובץ Google Sheets הקיים של החווה, "Vanilla grow assitant". האפליקציה עובדת רק עם הלשוניות שכבר קיימות בו, ולא יוצרת לשוניות חדשות ולא מוחקת כלום:

| לשונית | מה יש בה |
|---|---|
| **Master Data** | הנתונים הקבועים של החממות. כל עמודה היא חממה, והשמות בשורה הראשונה הם רשימת החממות באפליקציה |
| **Work** | רשימת העבודות. נוספו לה 4 עמודות בסוף: כל כמה ימים, יחידת כמות, מיקום, מעקב תדירות |
| **Log data** | כל הפעולות היומיות: עבודה בחממה, כניסה ויציאה מהעבודה, דיווחי בעיות ותמונות (הקישורים בעמודה "חומרים / תמונות"). נוספו עמודות בסוף: סטטוס, מזהה, קוד עבודה, יחידה, חומרה, פתרון |
| **Calendar** | יומן העבודות העתידיות: תאריך ביצוע, חממה, משימה, עובד, סטטוס |
| **Code** | ההגדרות: קודי הכניסה, רשימת העובדים (בשורה "עובדים", מופרדים בפסיק), מיילים ותיקיות |
| **Barcode** | קישור לדיווח לכל חממה. הופכים אותו ל-QR ומדביקים על הדלת |

בעמודה "קוד עבודה" ב-Log data מסומן סוג השורה: קוד העבודה (W01 וכו'), SHIFT ליום עבודה, ISSUE לבעיה, PHOTO לתמונות.

## התקנה (פעם אחת)

1. **השרת.** בקובץ "Vanilla grow assitant": תוספים, Apps Script. מדביקים את `apps-script/Code.gs` במקום הקוד הקיים. בהגדרות הפרויקט (גלגל השיניים) מסמנים "הצגת קובץ המניפסט appsscript.json" ומדביקים בו את `apps-script/appsscript.json`. שומרים.
2. **הרשאות.** בוחרים למעלה את הפונקציה `authorize` ולוחצים "הפעלה". Google תציג "Google hasn't verified this app": לוחצים Advanced, ואז Go to (unsafe), ואז Allow. זה תקין, כי הסקריפט שלכם. אחר כך מריצים באותה דרך את `installTriggers`, שמתקין את עדכון מזג האוויר היומי ב-06:00 ואת הגיבוי הלילי ב-02:00.
3. **פריסה באותה כתובת.** Deploy, Manage deployments, עיפרון על הפריסה הקיימת, Version: New version, Execute as: Me, Who has access: **Anyone**, Deploy. הכתובת נשארת זו שבלשונית Code, והאתר כבר מכוון אליה.
4. **בלשונית Code** מחליפים את קוד העובדים ואת קוד המנהל בקודים עם אותיות ומספרים, וממלאים את השורה "עובדים".
5. **QR.** בדשבורד לוחצים "הדפסת QR", או משתמשים בקישורים שבלשונית Barcode.

## בדיקה ראשונה בטלפון

סורקים את ה-QR של חממה 1, מקלידים קוד עובדים, בוחרים שם ועבודה ולוחצים כניסה. אחרי דקה לוחצים יציאה. בלשונית **Log data** אמורה להופיע שורה עם מזהה שמתחיל ב-L, שעת כניסה ויציאה וסטטוס "סגור". אחר כך, בדשבורד, מעלים תמונה אחת. ב-Drive תיווצר תיקייה "חממות וניל - תמונות".

## חזרה לגרסה הקודמת

לפני שמדביקים את הקוד החדש, כדאי להעתיק את הקוד הישן לקובץ טקסט. אם משהו לא עובד, ב-Deploy, Manage deployments, עורכים את הפריסה ובוחרים ב-Version את הגרסה הקודמת. הנתונים בקובץ לא משתנים, כי האפליקציה רק מוסיפה שורות.

## עדכונים

- שינוי בשרת: עורכים ב-Apps Script, ואז Deploy, Manage deployments, עריכה, New version. הכתובת לא משתנה.
- שינוי באתר: שומרים את הקובץ ב-GitHub. הטלפונים מקבלים את הגרסה החדשה בטעינה הבאה.
- עבודה, חממה או עובד חדשים: מוסיפים שורה בגיליון. האתר קורא את הרשימות בכל פתיחה.

## שעון נוכחות

במסך הדיווח: "כניסה לעבודה" בתחילת היום ו"יציאה מהעבודה" בסופו. כל יום עבודה נרשם כשורה בלשונית **Log data** (קוד SHIFT). מתחת מופיע "היום שלי", עם כל העבודות, הכמויות, התמונות והבעיות של היום לפי שעה. כניסה לחממה בלי כניסה לעבודה פותחת את יום העבודה אוטומטית. בדשבורד, הכרטיס "נוכחות היום" מראה מי בעבודה עכשיו ואיפה.

## תמונות ומשימות

את התמונות מעלה המנהל בדשבורד, בכרטיס **תמונות**: בוחרים חממה, תאריך והערה, ומעלים עד 20 תמונות בבת אחת. הן נשמרות כשורה בלשונית **Log data**, עם הקישורים בעמודה "חומרים / תמונות", ובתיקייה ב-Drive.

הכפתור **עבודות עתידיות** בדשבורד פותח רשימת משימות. לכל משימה בוחרים חממה, עבודה (או טקסט חופשי), תאריך לביצוע, ואם רוצים גם עובד. העובדים רואים במסך הדיווח את המשימות שלהם לשבוע הקרוב ומסמנים "בוצע". הכול נשמר בלשונית **Calendar**.

## גיבוי

כל לילה ב-02:00 נשמר עותק מלא של הגיליון בתיקייה "חממות וניל - גיבויים" ב-Drive. גיבויים בני יותר מ-30 יום (אפשר לשנות בלשונית **Code**) עוברים לפח, ואפשר לשחזר אותם משם עוד 30 יום. אם ממלאים בלשונית Code את **אימייל בעלים שני**, החשבון הזה מקבל הרשאת עריכה לגיליון, לגיבויים ולתמונות, כך שהנתונים לא תלויים בחשבון אחד. בדשבורד מופיעים זמן הגיבוי האחרון ונפח ה-Drive, ויש כפתור "גיבוי עכשיו". הגיבוי הלילי מותקן יחד עם עדכון מזג האוויר, בהרצה של `installTriggers`.
