# מעקב חממות וניל

אתר דיווח לעובדים ודשבורד למנהל. הנתונים נשמרים ב-Google Sheets, והשרת הוא Cloudflare Worker. מזג האוויר מגיע מ-Open-Meteo (מודל ECMWF, שנמדד כמדויק ביותר לשניר).

```
docs/           האתר (GitHub Pages). קבצים סטטיים בלבד, בלי שלב בנייה
worker/         השרת (Cloudflare Worker): index.js ו-wrangler.toml
scripts/        בדיקות: worker-test.mjs (השרת מול גוגל מדומה), e2e.js ו-mock-server.js (האתר)
apps-script/    השרת הישן (Google Apps Script). לא בשימוש, נשמר רק לגיבוי
research/       מחקר על מערכות מעקב ואגרונומיה של וניל
```

## איפה הנתונים נשמרים

כל הנתונים נשמרים בקובץ Google Sheets הקיים של החווה, "Vanilla grow assitant". האפליקציה עובדת רק עם הלשוניות שכבר קיימות בו, ולא יוצרת לשוניות חדשות ולא מוחקת כלום:

| לשונית | מה יש בה |
|---|---|
| **Master Data** | הנתונים הקבועים של החממות. כל עמודה היא חממה, והשמות בשורה הראשונה הם רשימת החממות באפליקציה |
| **Work** | רשימת העבודות. נוספו לה 4 עמודות בסוף: כל כמה ימים, יחידת כמות, מיקום, מעקב תדירות |
| **Log data** | כל הפעולות היומיות: עבודה בחממה, כניסה ויציאה מהעבודה, דיווחי בעיות ותמונות (הקישורים בעמודה "חומרים / תמונות"). נוספו עמודות בסוף: סטטוס, מזהה, קוד עבודה, יחידה, חומרה, פתרון |
| **Calendar** | יומן העבודות העתידיות: תאריך ביצוע, חממה, משימה, עובד, סטטוס |
| **Code** | ההגדרות: רשימת העובדים (בשורה "עובדים", מופרדים בפסיק), מיילים ותיקיות |
| **Barcode** | קישור לדיווח לכל חממה. הופכים אותו ל-QR ומדביקים על הדלת |

בעמודה "קוד עבודה" ב-Log data מסומן סוג השורה: קוד העבודה (W01 וכו'), SHIFT ליום עבודה, ISSUE לבעיה, PHOTO לתמונות.

## השרת (Cloudflare)

השרת הוא Worker בשם `vanilla-greenhouses` בחשבון Cloudflare של cortado.snir, בכתובת https://vanilla-greenhouses.cortado-snir.workers.dev. הוא פונה לגוגל בשם cortado.snir@gmail.com, ולכן החשבון הזה צריך להיות עורך בקובץ, בתיקיית התמונות ובתיקיית הגיבויים.

ההגדרות ב-Cloudflare (Worker, Settings):

| שם | סוג | מה זה |
|---|---|---|
| `SHEET_ID` | משתנה | המזהה של הקובץ Vanilla grow assitant |
| `ALLOWED_EMAIL` | משתנה | החשבון היחיד שמותר לחבר לגוגל |
| `GOOGLE_CLIENT_ID` | משתנה | מזהה החיבור מ-Google Cloud (פרויקט vanilla-greenhouses) |
| `GOOGLE_CLIENT_SECRET` | סוד | המפתח של החיבור. לא כותבים אותו בשום מקום אחר |
| `WORKER_CODE` | סוד | קוד העובדים, לפחות 8 אותיות ומספרים |
| `MANAGER_CODE` | סוד | קוד המנהל, לפחות 8 |
| `STORE` | KV | שומר את החיבור לגוגל |
| `0 0 * * *` | Cron | הגיבוי הלילי (02:00 בחורף, 03:00 בקיץ) |

**חיבור לגוגל (פעם אחת, או אם החיבור נותק):** פותחים את https://vanilla-greenhouses.cortado-snir.workers.dev/connect, נכנסים עם cortado.snir ומאשרים.

**החלפת קוד:** ב-Cloudflare, Settings, מחליפים את `WORKER_CODE` או `MANAGER_CODE`. בטלפונים מקלידים את הקוד החדש.

## בדיקה ראשונה בטלפון

סורקים את ה-QR של חממה 1, מקלידים קוד עובדים, בוחרים שם ועבודה ולוחצים כניסה. אחרי דקה לוחצים יציאה. בלשונית **Log data** אמורה להופיע שורה עם מזהה שמתחיל ב-L, שעת כניסה ויציאה וסטטוס "סגור". אחר כך, בדשבורד, מעלים תמונה אחת. ב-Drive תיווצר תיקייה "חממות וניל - תמונות".

## עדכונים

- שינוי בשרת: עורכים את `worker/index.js`, ומדביקים אותו ב-Cloudflare (Worker, Edit code, Deploy). ב-Deployments אפשר לחזור לגרסה קודמת בלחיצה.
- שינוי באתר: שומרים את הקובץ ב-GitHub. הטלפונים מקבלים את הגרסה החדשה בטעינה הבאה.
- עבודה, חממה או עובד חדשים: מוסיפים שורה בגיליון. האתר קורא את הרשימות בכל פתיחה.

## שעון נוכחות

במסך הדיווח: "כניסה לעבודה" בתחילת היום ו"יציאה מהעבודה" בסופו. כל יום עבודה נרשם כשורה בלשונית **Log data** (קוד SHIFT). מתחת מופיע "היום שלי", עם כל העבודות, הכמויות, התמונות והבעיות של היום לפי שעה. כניסה לחממה בלי כניסה לעבודה פותחת את יום העבודה אוטומטית. בדשבורד, הכרטיס "נוכחות היום" מראה מי בעבודה עכשיו ואיפה.

## תמונות ומשימות

את התמונות מעלה המנהל בדשבורד, בכרטיס **תמונות**: בוחרים חממה והערה, ומעלים עד 20 תמונות בבת אחת. הן נשמרות בתיקיית התמונות ב-Drive (המזהה שלה בלשונית Code), ובלשונית **Log data** נוספת שורה עם תאריך ושעת ההעלאה והקישורים בעמודה "חומרים / תמונות".

הכפתור **עבודות עתידיות** בדשבורד פותח רשימת משימות. לכל משימה בוחרים חממה, עבודה (או טקסט חופשי), תאריך לביצוע, ואם רוצים גם עובד. העובדים רואים במסך הדיווח את המשימות שלהם לשבוע הקרוב ומסמנים "בוצע". הכול נשמר בלשונית **Calendar**.

## גיבוי

כל לילה ב-02:00 נשמר עותק מלא של הגיליון בתיקייה "חממות וניל - גיבויים" ב-Drive. גיבויים בני יותר מ-30 יום (אפשר לשנות בלשונית **Code**) עוברים לפח, ואפשר לשחזר אותם משם עוד 30 יום. אם ממלאים בלשונית Code את **אימייל בעלים שני**, החשבון הזה מקבל הרשאת עריכה לגיליון, לגיבויים ולתמונות, כך שהנתונים לא תלויים בחשבון אחד. בדשבורד מופיעים זמן הגיבוי האחרון ונפח ה-Drive, ויש כפתור "גיבוי עכשיו". הגיבוי הלילי רץ מ-Cloudflare (Cron).

## אבטחה

- הקובץ, תיקיית התמונות ותיקיית הגיבויים צריכים להיות משותפים רק לאנשים מסוימים, לא "כל מי שיש לו את הקישור". מי שיכול לערוך את הקובץ יכול גם לערוך את הסקריפט.
- cortado.snir@gmail.com חייב להישאר עורך בקובץ ובתיקיות, כי השרת עובד בשמו.
- אחרי כל שינוי שיתוף מחליפים את שני הקודים ב-Cloudflare.
- הקודים שמורים כסודות ב-Cloudflare, לא בגיליון.
- השרת בודק כל בקשה: מזהה בפורמט קבוע, זמן שאינו בעתיד ולא ישן משבוע, יציאה אחרי כניסה, ותמונות JPEG בלבד בגודל מוגבל. אין נעילה אחרי ניסיונות שגויים, כי נעילה הייתה מאפשרת לכל אחד לחסום את החווה. הקודים הארוכים הם ההגנה.
