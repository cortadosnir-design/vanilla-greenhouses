# מעקב חממות וניל

אתר דיווח לעובדים ודשבורד למנהל. הנתונים נשמרים ב-Google Sheets, והשרת הוא Google Apps Script. מזג האוויר מגיע מ-Open-Meteo (מודל ECMWF, שנמדד כמדויק ביותר לשניר).

```
docs/           האתר (GitHub Pages). קבצים סטטיים בלבד, בלי שלב בנייה
apps-script/    השרת. Code.gs ו-appsscript.json, מודבקים לעורך של Apps Script
scripts/        build_workbook.py (בונה את הגיליון), mock-server.js, e2e.js ו-gas-harness.js (בדיקות)
research/       מחקר על מערכות מעקב ואגרונומיה של וניל
```

## התקנה (פעם אחת)

1. **הגיליון.** מעלים את `vanilla-greenhouses.xlsx` ל-Google Drive, פותחים אותו ושומרים כ-Google Sheets (קובץ, שמירה כ-Google Sheets). בקובץ, הגדרות, מוודאים שאזור הזמן הוא ירושלים. ממלאים את הלשונית **עובדים**. בלשונית **הגדרות** מחליפים את שני הקודים בקודים עם אותיות ומספרים (קוד שמתחיל ב-0 מאבד את האפס), וכותבים מייל לעדכון היומי.
2. **השרת.** בגיליון: תוספים, Apps Script. מדביקים את `apps-script/Code.gs` במקום כל הקוד הקיים. בהגדרות הפרויקט (גלגל השיניים) מסמנים "הצגת קובץ המניפסט appsscript.json" ומדביקים בו את `apps-script/appsscript.json`. שומרים.
3. **הרשאות.** בוחרים למעלה את הפונקציה `authorize` ולוחצים "הפעלה". Google תציג "Google hasn't verified this app": לוחצים Advanced, ואז Go to (unsafe), ואז Allow. זה תקין, כי הסקריפט שלכם. אחר כך מריצים באותה דרך את `installTriggers`, שמתקין את עדכון מזג האוויר היומי ב-06:00.
4. **פריסה.** Deploy, New deployment, סוג Web app. Execute as: Me. Who has access: **Anyone**. מעתיקים את הכתובת שמסתיימת ב-`/exec`. פותחים אותה בחלון גלישה בסתר, ואמורים לראות `{"ok":true,...}`.
5. **חיבור האתר.** ב-GitHub פותחים את `docs/config.js` (סמל העיפרון), מדביקים את הכתובת החדשה במקום הישנה ושומרים. הכתובת הישנה מציגה את הטופס הקודם ולא תעבוד עם האתר החדש.
6. **האתר.** ב-GitHub: Settings, Pages, Source: Deploy from a branch, branch `main`, תיקייה `/docs`. הכתובת תופיע תוך דקה.
7. **QR.** בדשבורד לוחצים "הדפסת QR" ומדביקים כל קוד על דלת החממה שלו.

## בדיקה ראשונה בטלפון

סורקים את ה-QR של חממה 1, מקלידים קוד עובדים, בוחרים שם ועבודה ולוחצים כניסה. אחרי דקה לוחצים יציאה. בלשונית **יומן עבודה** אמורה להופיע שורה עם מזהה שמתחיל ב-L, שעת כניסה ויציאה וסטטוס "סגור". אחר כך, בדשבורד, מעלים תמונה אחת. ב-Drive תיווצר תיקייה "חממות וניל - תמונות".

## חזרה למערכת הישנה

לא נוגעים בגיליון ובסקריפט הישנים, והם ממשיכים לעבוד בכתובת הישנה. אם משהו לא עובד, מחזירים את הכתובת הישנה ל-`docs/config.js`.

## עדכונים

- שינוי בשרת: עורכים ב-Apps Script, ואז Deploy, Manage deployments, עריכה, New version. הכתובת לא משתנה.
- שינוי באתר: שומרים את הקובץ ב-GitHub. הטלפונים מקבלים את הגרסה החדשה בטעינה הבאה.
- עבודה, חממה או עובד חדשים: מוסיפים שורה בגיליון. האתר קורא את הרשימות בכל פתיחה.

## שעון נוכחות

במסך הדיווח: "כניסה לעבודה" בתחילת היום ו"יציאה מהעבודה" בסופו. כל יום נרשם בלשונית **נוכחות**. מתחת מופיע "היום שלי", עם כל העבודות, הכמויות, התמונות והבעיות של היום לפי שעה. כניסה לחממה בלי כניסה לעבודה פותחת את יום העבודה אוטומטית. בדשבורד, הכרטיס "נוכחות היום" מראה מי בעבודה עכשיו ואיפה.

## תמונות ומשימות

את התמונות מעלה המנהל בדשבורד, בכרטיס **תמונות**: בוחרים חממה, תאריך והערה, ומעלים עד 20 תמונות בבת אחת. הן נשמרות בלשונית **תמונות** ובתיקייה ב-Drive.

הכפתור **עבודות עתידיות** בדשבורד פותח רשימת משימות. לכל משימה בוחרים חממה, עבודה (או טקסט חופשי), תאריך לביצוע, ואם רוצים גם עובד. העובדים רואים במסך הדיווח את המשימות שלהם לשבוע הקרוב ומסמנים "בוצע". הכול נשמר בלשונית **משימות**.
